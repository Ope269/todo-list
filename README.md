# My To-Do List App

## About the Project
My To-Do List App is a simple task management web application built to help users organize their daily activities. Users can add new tasks, mark tasks as completed, and delete tasks when they are no longer needed.

This is my beginner frontend development project, created to practise my HTML, CSS, and JavaScript skills.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Simple and user-friendly interface.
- Responsive layout for different screen sizes.

## Technologies Used
- **HTML5** — To structure the webpage.
- **CSS3** — To style the application.
- **JavaScript** — To add interactivity.

## How to Use
1. Open the To-Do List application in your browser.
2. Enter a task in the input field.
3. Click the **Add Task** button.
4. Click **Done** to mark a task as completed.
5. Click **Delete** to remove a task.
